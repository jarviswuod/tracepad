# 17.3 · Date separators on the note lists

**Goal:** Split note lists with a clear date heading, so notes from different days aren't mixed together. The heading follows the sort: modified date or created date.

**Spec:** Flow §6 (board, both sorts, pinned stay on top). The owner approved this after task 17.1. Schema: `notes.created_at`, `notes.updated_at`.

**Model:** Claude Sonnet 5.5.

**Prompt:**

```text
Read AGENTS.md, brief.md and section 6 of docs/Tracepad-Full-Flow.md. Then read web/src/features/board/Board.tsx and web/src/data/notes.ts.
Do task 17.3. The owner approved this:
- On every notes page (Home, Reminders, Archive, Trash, and each label), group the cards by day. Recently edited groups by updatedAt. Newest created groups by createdAt.
- A heading spans the full width between groups: "Today", "Yesterday", then "November 25" for this year and "November 25, 2025" for other years. The heading is a separator, not a card.
- Pinned stay in their own section, above Others. Each of those two sections has its own date headings.
- Search results are grouped the same way. The history page is a timeline and stays as it is.
- Order inside a day is unchanged.
Always write tests for the feature you're building, before or alongside the code. Then run ./tests/run-all.sh; every test must pass. Report.
```

**Done when:**

- A unit test: a note from today, one from yesterday and one from last year produce those three headings. Switching the sort switches which timestamp is used. Pinned and others are grouped apart.
- A Playwright test: two notes edited on different days show two headings on Home, on Archive, and on a label. Changing the sort to Newest created uses the created date.
- `./tests/run-all.sh` exits 0.
