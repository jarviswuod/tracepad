# 14.1 · Stay on the current view after a refresh

**Goal:** The address bar shows where you are, and a refresh keeps you there: Notes, Archive, Trash, Reminders or a label.

**Spec:** Flow §6 (board views) and §19 Phase 1 UI (the side list). The owner approved this after task 14. Schema: `labels`.

**Model:** Claude Sonnet 5.5.

**Prompt:**

```text
Read AGENTS.md, brief.md, section 6 and the Phase 1 "UI" paragraph of section 19 in docs/Tracepad-Full-Flow.md. Then read web/src/app/AppRoutes.tsx, AppShell.tsx, web/src/features/board/Board.tsx, web/src/features/editor/NotesHome.tsx and web/src/features/history/History.tsx.
Do task 14.1. The view is React state, so a refresh always returns to Notes. The owner wants the URL to be the view, and a refresh to stay there:
- /home is Notes. / goes to /home.
- /archive, /trash and /reminders.
- /label/<name> for a label, with the name encoded. A label called "trash" or "home" still uses /label/, so it can't clash with the other paths. Renaming the open label updates the URL. Deleting it goes to /home. An unknown name shows that label's empty view, not an error.
- The side list on the board and on history navigates to these paths. Derive the view from the URL. Don't keep it in state.
- Sort and grid/list stay as they are. Don't put them in the URL.
- "Back to note" returns to the view you opened history from, and still opens that note once. Keep the existing fix that a refresh does not reopen it.
- Opening a note, creating one, and the modals don't change.
Always write tests for the feature you're building, before or alongside the code. Then run ./tests/run-all.sh; every test must pass. Report.
```

**Done when:**
- A route test maps each path to the right view, encodes a label name, and sends `/` to `/home`.
- A Playwright test: open Archive, Trash, Reminders and a label, reload on each, and you're still there. Open one by typing its URL. Rename the open label and the URL changes. "Back to note" returns to that view, and a reload does not reopen the note.
- `./tests/run-all.sh` exits 0.
