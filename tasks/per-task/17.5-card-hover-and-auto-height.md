# 17.5 · Hover actions and auto height

**Goal:** Hovering a note shows the same actions as opening it, with the spacing in the owner's Keep screenshot. The create box grows with its content the way the open note already does.

**Spec:** Flow §6, §7 and §8. The owner approved this after task 17.1 and pointed at a Keep board screenshot. Schema: none.

**Model:** Claude Sonnet 5.5.

**Prompt:**

```text
Read AGENTS.md, brief.md, and sections 6, 7 and 8 of docs/Tracepad-Full-Flow.md. Then read web/src/features/board/Board.tsx and board.css, and web/src/features/editor/Editor.tsx and editor.css. The open note grows (editor-body-expand). The create box does not: its textarea has a fixed min-height and resize: vertical.
Do task 17.5. The owner approved this, matching the Keep screenshot:
- Hovering a card, or moving keyboard focus onto it, reveals the same actions the open note offers: Pin, Remind me, and More (Archive, labels, colors, version history, delete). They sit in one row at the bottom of the card, icon size, with about 8px between them. A click on an action does that action and does not open the note. A click on the card still opens it.
- Padding is 12px 16px, like the screenshot. The row fits inside the card. Nothing is clipped, and the title does not sit under the icons. The card grows to fit the row.
- The create box grows and shrinks with the text and with checklist items added or removed, the same way the open note does. Remove the fixed 5rem body and the manual resize. The open note keeps growing too.
- The row is hidden when the pointer leaves. On a narrow screen it stays visible, since there is no hover.
Don't add image, drawing, or collaborator actions.
Always write tests for the feature you're building, before or alongside the code. Then run ./tests/run-all.sh; every test must pass. Report.
```

**Done when:**

- A component test: the card's action row is hidden, appears on hover, and Pin from that row pins the note without opening it.
- A Playwright test: the create box grows when text past one line is typed and when a checklist item is added, with no inner scrollbar. The open note still grows. A hovered card shows the action row inside its padding, and the card is tall enough that the row isn't cut off.
- `./tests/run-all.sh` exits 0.
