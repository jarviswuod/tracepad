# 15.2 · Reminder default time, no seconds, and a soft alarm

**Goal:** A new reminder opens on today's date, three hours ahead, with no seconds. When it fires, a soft tone plays for five seconds as well as the notification.

**Spec:** Flow §13 (set a reminder, refuse a past time, fire while the tab is open, missed reminders on the next open). The owner approved this after task 15. Schema: `reminders.fire_at`.

**Model:** Claude Sonnet 5.5.

**Prompt:**

```text
Read AGENTS.md, brief.md and section 13 of docs/Tracepad-Full-Flow.md. Then read web/src/features/reminders/ReminderControl.tsx, ReminderRuntime.tsx, notify.ts and engine.ts.
Do task 15.2. The owner approved this:
- Opening Remind me on a note with no reminder prefills the current local date and the time three hours from now. If that crosses midnight, the date is the next day. Seconds are zero. Opening an existing reminder shows its saved time, still with no seconds.
- The field has no seconds: step is 60, and the value is YYYY-MM-DDTHH:mm. Store fireAt with seconds and milliseconds at zero. "Pick a future time." still applies.
- When a reminder fires on time, keep the notification and also play a soft tone for 5 seconds. Generate it with the Web Audio API. No audio file and no new library. Keep the volume low. Start the audio context on the first click or when a reminder is saved, so a later timer can play. If the browser blocks the sound, the notification still shows.
- A reminder found missed on startup stays a notice. It does not play the tone.
Don't change who fires, or the pause while a note is trashed.
Always write tests for the feature you're building, before or alongside the code. Then run ./tests/run-all.sh; every test must pass. Report.
```

**Done when:**
- A unit test: three hours ahead of a fixed clock, including a time that crosses midnight, with seconds at zero. An existing reminder is not replaced by that default.
- A test: the field value has no seconds, and a saved reminder's fireAt has seconds and milliseconds at zero.
- A test with a fake audio context: an on-time fire starts the tone and stops it at 5 seconds. A missed reminder on startup does not start it. The notification still shows when audio is refused.
- `./tests/run-all.sh` exits 0.
