# 17.1 · Masonry grid and drag order

**Goal:** In grid layout, each note keeps its own height and the next card drops into the shortest column. Dragging a card there reorders the notes and that order is remembered.

**Spec:** Flow §6 (the board; custom drag order is listed as v2). The owner approved it now, using the schema field `notes.sort_position`. Schema: `notes.sort_position`.

**Model:** Claude Sonnet 5.5.

**Prompt:**

```text
Read AGENTS.md, brief.md, and section 6 of docs/Tracepad-Full-Flow.md. Then read web/src/features/board/Board.tsx and board.css, web/src/domain/types.ts, and web/src/data/db.ts. The board already sets grid-template-rows: masonry. Chrome ignores that, so every card in a row is as tall as the tallest one.
Do task 17.1. The owner approved this, and chose Muuri (the muuri package) because it packs by height and drags like Google Keep. No other library.
- Grid only. List stays one column, in the current order, with no dragging. The history page is unchanged.
- In grid, a card is as tall as its own text. The next card goes into the shortest column. Pinned and Others are two separate packs, with their headings kept. A drag cannot cross that boundary. Pin still moves a note between them.
- Add notes.sortPosition (the schema's sort_position) to the Note type and the IndexedDB note store. Existing notes get null. Bump the database version.
- Add "Custom" to the sort. Dragging a card in the grid saves its sortPosition, writes one note outbox row, and switches the sort to Custom. It cuts no version and no history entry, and it does not change updatedAt. Recently edited and Newest created still order by those times while they are selected. Pinned stay in their own group on every sort.
- A click still opens the note. A drag starts only after the pointer moves a few pixels. Dragging is off while a search is showing.
- Reflow when the window or a card's height changes.
Always write tests for the feature you're building, before or alongside the code. Then run ./tests/run-all.sh; every test must pass. Report.
```
