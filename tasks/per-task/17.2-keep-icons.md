# 17.2 · Google Keep icons

**Goal:** Replace the word-only buttons with the same icons Google Keep uses, including up and down arrows on checklist items. The action behind each button stays the same.

**Spec:** Flow §10, §11 and §13, and the Phase 1 "UI" paragraph in §19. The owner approved icons after task 17.1. Schema: none.

**Model:** Claude Sonnet 5.5.

**Prompt:**

```text
Read AGENTS.md, brief.md, and sections 10, 11 and 13 of docs/Tracepad-Full-Flow.md. Then read the buttons in web/src/features/board/, editor/, labels/, reminders/, trash/ and history/.
Do task 17.2. The owner approved this, matching Google Keep's icons:
- Draw them as inline SVG, 24px, in currentColor. No icon font and no new package.
- Icon only, with the current words kept as the accessible name (aria-label), so a screen reader still hears "Archive" or "Pin". Add a title tooltip with that same word.
- Use Keep's icon for each action that already exists: pin and unpin, remind, archive and unarchive, more (three dots), change labels, colors, version history, delete (trash can), close, restore, checklist on and off, add checklist item, and remove item. Side list: notes, reminders, archive, trash, edit labels. Layout toggle: grid and list.
- Checklist Up and Down become an up arrow and a down arrow. Remove the visible words.
- Don't add actions Tracepad doesn't have. No image, drawing, or collaborator buttons.
Always write tests for the feature you're building, before or alongside the code. Then run ./tests/run-all.sh; every test must pass. Report.
```

**Done when:**

- A component test: each of those buttons has an svg and no visible word, and its accessible name is unchanged. Checklist items have up and down arrows and no "Up" or "Down" text.
- A Playwright test: the open note's pin, remind, archive and more controls show icons. A checklist item moves up from the arrow.
- `./tests/run-all.sh` exits 0.
