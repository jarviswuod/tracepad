# 17.4 · Note type, label size, and no focus ring

**Goal:** Make the note title larger, the body easier to read, and the label chips the same size as the note text. Remove the focus outline on note and label fields.

**Spec:** Flow §6 and §10, and the Phase 1 "UI" paragraph in §19. The owner approved this after task 17.1. Schema: none.

**Model:** Claude Sonnet 5.5.

**Prompt:**

```text
Read AGENTS.md and brief.md. Then read web/src/features/editor/editor.css, web/src/features/board/board.css and web/src/features/labels/labels.css.
Do task 17.4. The owner approved this, for creating a note and for viewing or editing one, and for labels too:
- Body text is 1rem with line-height 1.5, in the create box, the open note, and the card preview. The current line height is too tight.
- The title is two steps larger than the body: 1.5rem, weight 500. Same size on the card, in the create box, and in the open note.
- A label chip uses that same 1rem body size and the note's padding, on the card and in the open note. Don't leave the chips at 0.75rem.
- Remove the focus outline on the title, the body, checklist item fields, and label name fields. A selected color swatch keeps its ring, since that ring means "selected", not "focused".
- Don't change the side list or the dialogs' buttons.
Always write tests for the feature you're building, before or alongside the code. Then run ./tests/run-all.sh; every test must pass. Report.
```

**Done when:**

- A component test: the title computes to 1.5rem and the body to line-height 1.5, both while creating and while open. A label chip computes to 1rem. Focusing the title, body and a label field leaves outline-style none.
- A Playwright test at the create box and on an open note confirms those sizes.
- `./tests/run-all.sh` exits 0.
