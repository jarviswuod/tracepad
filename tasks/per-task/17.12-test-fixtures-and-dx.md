**Goal:** Tests build notes and databases from one shared place instead of 21 copies, and the web app has a few clear commands for checking work before a commit.

**Spec:** Flow §17 (tests live inside each part). The owner approved this after checkpoint 1. Do task 17.11 first. Schema: `docs/Tracepad-Schema.md` field names.

**Model:** Claude Sonnet 5.5.

**Prompt:**

```text

Do task 17.12. The owner approved this.

Always write tests for the feature you're building, before or alongside the code. Then run ./tests/run-all.sh; every test must pass. Report how many local helpers you removed, the new scripts, and the README sections you changed.
```
