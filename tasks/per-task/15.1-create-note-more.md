# 15.1 · More on a new note, with Remind me and Archive inside it

**Goal:** Move "Remind me" and "Archive" into the More menu, and show that More button while a note is being created, not only after it opens in the modal.

**Spec:** Flow §7 (create), §8 (empty note), §10 (archive) and §13 (reminders). The owner approved this after task 15. Schema: `notes`, `reminders`, `history_events`, `outbox`.

**Model:** Claude Sonnet 5.5.

**Prompt:**

```text
Read AGENTS.md, brief.md, and sections 7, 8, 10 and 13 of docs/Tracepad-Full-Flow.md. Then read web/src/features/labels/NoteMeta.tsx (NoteToolbar), web/src/features/reminders/ReminderControl.tsx, web/src/features/editor/Editor.tsx and NotesHome.tsx.
Do task 15.1. The owner approved this:
- On an open note, "Remind me" and "Archive" leave the toolbar and become items in More, with Change labels, Colors, Version history and Delete note. The toolbar keeps More and Close. A trashed note still has Restore and Delete forever, and no More.
- "Take a note" gets the same More button. Its menu has Remind me and Archive only.
- A new note may have no row yet. The first Archive or Remind me saves it through the existing draft path, then uses setArchived or setReminder. Don't write a second save path.
- The owner decided an archived note, or one with a reminder, is kept even when the title and body are empty. Any other empty note is still discarded.
- Remind me still sets, changes and removes the one reminder, and still refuses a past time. Archive still writes a history entry and no version.
Update the tests that expect Remind me and Archive as their own toolbar buttons.
Always write tests for the feature you're building, before or alongside the code. Then run ./tests/run-all.sh; every test must pass. Report.
```

- Component tests: an open note's toolbar is More and Close; More lists Remind me and Archive with the four existing items. The create box has More, and its menu lists only those two. A trashed note is unchanged.
- A test: archiving or setting a reminder on a blank new note creates the row and keeps it. Leaving a blank note with neither still creates nothing.
- A Playwright test: click Take a note, open More, archive it, and it appears in Archive. Set a reminder from that same menu.
- `./tests/run-all.sh` exits 0.
