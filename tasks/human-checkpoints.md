# Tracepad human checkpoints: version 1

After each phase, the owner checks the build by hand before any agent starts the next phase. An agent must not start a task from the next phase until that checkpoint's sign-off line below is filled in.

Each check has three parts: **Do** (what to open, run or tap), **Looks right** (what you should see), and **Outcome** (what the check proves, with the section of `docs/Tracepad-Full-Flow.md` it comes from). If any check fails, don't sign off. Note the check number and what you saw, and give it to an agent as a fix task in the same phase.

## Checkpoint 3: Android, and version 1 done (after tasks 30 to 35)

**Just finished:** Phase 3. The Android app does everything the web app does, and syncs with it.

### Install on your phone

1. On the phone: Settings → About phone → tap **Build number** 7 times. Then Settings → System → Developer options → turn on **USB debugging**.
2. Connect the phone by USB and accept the "Allow USB debugging?" prompt. On the laptop, `adb devices` should list your phone as `device`.
3. From the repo root: `docker compose up -d`.
4. `cd android && ./gradlew installDebug`. Expect `BUILD SUCCESSFUL` and `Installed on 1 device`. Tracepad's icon appears in the app drawer.
5. Let the phone reach the local server. If the debug build uses `http://localhost:8080`, run `adb reverse tcp:8080 tcp:8080` and keep the cable connected. Otherwise, put the phone on the same Wi-Fi and use the laptop's IP address, as set up in task 34.
6. Keep the web app open at http://localhost:5173, signed in.
